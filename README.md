# Meido: личный Discord-бот

Напоминания, которые не исчезают, пока не нажато «Готово»; повторяющиеся дела и сроки; интервальные таймеры. Бесплатно: Cloudflare Workers + D1, Discord по HTTP Interactions, без включённого ПК.

**Статус (2026-11-07):** ядро и установка написаны и проверены локально (189 тестов, сухой прогон, локальный движок Cloudflare, установка на поддельном wrangler). На настоящем Discord и Cloudflare ещё не запускалось: первый запуск — по шагам ниже, проверки — `LIVE-CHECKS.md`.

## Установка (около 15 минут)

Понадобится: ПК с Windows; **личные** аккаунты Discord (с вашим сервером) и Cloudflare (бесплатный, регистрация на dash.cloudflare.com: почта и пароль, карта не нужна); Node.js (если нет — `setup.cmd` подскажет и откроет ссылку).

### Шаг 1. Приложение в Discord (5 минут)

Откройте https://discord.com/developers/applications и войдите в Discord.

1. Нажмите **New Application**, имя `Meido`, галочка согласия, **Create**.
2. Вкладка **General Information**: рядом с **Application ID** нажмите **Copy** и вставьте куда-нибудь временно (например, в Блокнот). Так же скопируйте **Public Key**.
3. Вкладка **Installation** (слева). В блоке **Installation Contexts** поставьте обе галочки: **Guild Install** и **User Install**. В блоке **Install Link** выберите **None** (личное приложение не может иметь стандартную ссылку установки; бота вы добавите по нашим ссылкам, их напечатает `setup.cmd`). Блок **Default Install Settings** можно не трогать. Нажмите **Save**.
4. Вкладка **Bot**. Выключите переключатель **Public Bot** (бот личный). Если сверху красная ошибка «Private application cannot have a default authorization link», значит в шаге 3 **Install Link** ещё не **None**: вернитесь и поставьте. Нажмите **Reset Token** → **Yes, do it!** → **Copy**. **Токен виден один раз**: вставьте его в Блокнот. Никому не отправляйте его, в чат Claude тоже.
5. Там же, ниже, в **Privileged Gateway Intents** включите **Message Content Intent**. Нажмите **Save Changes**.

### Шаг 2. Запуск установки (5 минут)

В папке `DiscordBot` дважды щёлкните **setup.cmd**. Программа сама пройдёт все шаги:

- откроется браузер: войдите в **личный** Cloudflare и нажмите **Allow**. У бота свой отдельный вход (папка `.cf-home` рядом с ботом), общий вход wrangler на ПК, в том числе рабочий, он не использует и не меняет. Установка покажет почту аккаунта и спросит «Это ваш личный аккаунт?»; рабочую почту (`b-eng-s.com`) она не примет;
- при первой выкладке Cloudflare может спросить имя адреса `workers.dev` (регистрация бесплатная): впишите любое короткое, например своё имя латиницей; оно станет частью адреса бота;
- создаст базу, таблицы, выложит бота;
- спросит три значения из Блокнота (Application ID, Public Key, токен; токен при вводе не виден, это нормально) и необязательный адрес сторожа (его можно пропустить клавишей Enter);
- зарегистрирует команды в Discord.

В конце она напечатает адрес бота и ссылки. Если остановилась на ошибке, запустите `setup.cmd` ещё раз: сделанное повторно не сломается.

### Шаг 3. Три действия в Discord (3 минуты)

1. Developer Portal → **General Information** → поле **Interactions Endpoint URL**: вставьте адрес, который напечатала установка (`https://….workers.dev/interactions`), нажмите **Save Changes**. Если Discord пишет ошибку, значит Public Key введён неверно: запустите `setup.cmd` ещё раз и введите его заново.
2. Откройте ссылку «на сервер», которую напечатала установка, выберите свой сервер → **Authorize**. Затем ссылку «на аккаунт» → **Authorize**: так команды заработают в любом чате.
3. На своём сервере в любом канале напишите команду `/setup` (выберите её из списка). Бот заведёт каналы **напоминания**, **бот**, **сегодня**. Хозяином бота становится тот, кто выполнил `/setup` первым.

### Шаг 4. Первая запись

Зайдите в канал **бот** и напишите обычным текстом: `завтра в 10 купить хлеб`. Бот ответит «Записано …» с кнопками **Верно** и **Изменить** (до минуты задержки). Напоминания приходят в канал **напоминания** с упоминанием. Настройки (тихие часы, сводки, «я в отъезде», настойчивость) — команда `/settings`.

### Шаг 5. Сторож «бот жив» (3 минуты, по желанию, но рекомендуется)

На healthchecks.io зарегистрируйтесь → **Add Check**: имя `Meido`, **Period** 10 minutes, **Grace Time** 30 minutes → скопируйте **ping URL**. Запустите `setup.cmd` ещё раз: на вопросы про Application ID, Public Key и токен нажимайте Enter (оставить прежнее), а на вопрос про адрес сторожа вставьте скопированный. Если бот замолчит, придёт письмо.

## Что умеет бот

- Пишете текстом в канал «бот» или командами: `/remind` («завтра в 10 купить хлеб»), `/every` («каждые 20 минут проверить плиту до 23:00», «каждый месяц 20-го оплатить ФОП заранее за 7, 3 и 1 день», «каждую вторую пятницу в 15:00 отчёт»); на сообщении: долгое нажатие → Приложения → «Напомнить об этом».
- Пока не нажато **Готово**, бот повторяет (по умолчанию в 0, +10, +20, +40 минут, потом «просрочено»); кнопки **15 мин**, **1 час**, **На…**, **Изменить**. Настойчивость (мягко, стандартно, настойчиво или свои числа) задаётся при записи и потом.
- `/list`, `/week`, `/cancel`, `/snooze`, `/away` (я в отъезде), `/settings`; сводки утром и вечером, итоги недели по воскресеньям, панель «Горит» в канале «сегодня».
- График отключений света (Днепр, данные Yasno): `/settings` → «Свет: группа…» → вписать номер группы (например, `3`); строка появится в утренней и вечерней сводке.
- Характер: `/settings` → «Характер: уставшая горничная». По умолчанию бот нейтральный; горничная добавляет пару усталых слов только в мелочах (пустой список, «Готово», подпись сводок, `/setup`), сами напоминания не меняются.
- Пароли, ключи и номера карт бот не сохраняет и в журнал не пишет: пишите без значения, храните в менеджере паролей.

## Раз в какое-то время

```bash
npm run status   # всё ли работает: cron, каналы, число дел, проблемы за сутки
npm run export   # копия всех дел в файл backups/meido-ДАТА.sql (хранить надёжно)
```

Cloudflare Time Travel хранит и откатывает базу на любой момент за последние 7 дней.

## Где споткнуться

| Что видно | Что делать |
|---|---|
| Вкладка Bot: «Private application cannot have a default authorization link» | Installation → **Install Link** → **None** → Save |
| Discord не принимает Interactions Endpoint URL | Неверный Public Key или бот не выложен: `setup.cmd` ещё раз |
| Команд `/remind` нет в списке | Подождите минуту, перезапустите Discord (Ctrl+R); `npm run register` |
| `/setup`: «не получилось создать каналы» | У бота нет права «Управлять каналами»: добавьте бота по ссылке из установки ещё раз |
| Бот молчит на текст в канале «бот» | Включите Message Content Intent (шаг 1.5) или напишите `/settings` → «Личка: включить» и пишите боту в личные сообщения |
| Напоминания не приходят | `npm run status`; проверьте `/settings`: тихие часы, «я в отъезде» |
| Токен попал не туда | Developer Portal → Bot → Reset Token; затем `setup.cmd` и новый токен |

Сверено с кодом на 2026-11-07; на живом Discord и Cloudflare не проверено.

```bash
npm install
```
