# DiscordBot

Личный Discord-бот Ihor: напоминания, которые не исчезают, пока не нажато «Готово»; повторяющиеся дела и сроки; «Входящие» и наведение порядка в заметках (Meido). Бесплатно: Cloudflare Workers + D1, Discord по HTTP Interactions, без включённого ПК.
