# Разведка: источники для слежения за мангой и ранобэ (этап «Чтение»)

Дата: 2026-11-18. Решения Ihor — `docs/DECISIONS.md`, «Анкета вкусов, волна 2» (абзацы «Слежение за главами и томами», «Хару о чтении», «Форматы чтения», «Интерфейс») и «волна 3» (фраза «Прочитал Х», «Расхождение»); здесь они не пересматриваются. Пробы — с этого ПК, только запросы на чтение к открытым адресам (ключей нет, ничего не записывалось). **Из настоящего Cloudflare Worker MangaDex и MangaUpdates не пробовали** (выкладка и `wrangler` запрещены этой сессии): первая живая проверка после выкладки — `LIVE-CHECKS.md`.

## Коротко

- **У Shikimori нет живого счётчика для идущих тайтлов.** У всех идущих манги и ранобэ `chapters = 0` и `volumes = 0` (проверено: «Ван-Пис», «Фрирен», «Кауру Хана», «Sword Art Online», «Реинкарнация безработного» манга и ранобэ). Числа появляются только у закончившихся (`status: released`: «Магическая битва» 30 томов, 272 главы). Поэтому Shikimori даёт: поиск, русские названия, состояние (идёт / закончен / анонс / перерыв), итоговые цифры закончившихся и аниме по тайтлу (`/api/mangas/{id}/related`, relation «Adaptation»). Роста счётчика у него не видно.
- **Манга: MangaDex** (`api.mangadex.org`, без ключа, нужен свой `User-Agent`; по документации лимит около 5 запросов в секунду, мы ходим по паре запросов в минуту). Связь с Shikimori — по номеру MyAnimeList: `attributes.links.mal` совпадает с `id` Shikimori. `aggregate` отдаёт все главы по томам (2,5 КБ для 200 глав): наибольший номер главы и наибольший номер тома — это «вышла глава N» и «вышел том N» по росту между двумя ночными проверками. Отдельно по русскому (`translatedLanguage[]=ru`) видно, до какой главы перевод есть: у «Кауру Хана» английский до 199, русский до 149 — расхождение настоящее, поэтому в сообщении есть строка «по-русски на MangaDex до N». У многих глав есть `externalUrl` — официальная ссылка (у той же манги — Kodansha).
- **Ранобэ: MangaUpdates** (`api.mangaupdates.com/v1`, без ключа). Номера MAL там нет, склейка по названию (после снятия «(Novel)» заголовок должен совпасть целиком). Число томов — в тексте `status`: «28 Volumes (Ongoing)»; это ведут люди, оно может отставать. Поле `latest_chapter` у ранобэ ненадёжно (у SAO 25 при 28 томах), не используем. MangaDex ранобэ не содержит.
- **Не берём:** AniList (из Cloudflare заблокирован, `docs/RECON-ANIME.md`), Jikan (не отвечал и из ПК, и по прежней разведке), MyAnimeList напрямую (нужен ключ), сайты чтения по-русски (нет открытого интерфейса, закрытые сервисы).

## Что проверили

| Источник | Запрос | Результат |
|---|---|---|
| Shikimori | `GET /api/mangas?search=…&order=popularity`, `GET /api/ranobe?search=…` | 200; манга и ранобэ в разных списках, `kind`: `manga`, `light_novel`; ссылка у ранобэ тоже `/mangas/{id}` |
| Shikimori | `GET /api/mangas/{id}` | 200 и для манги, и для ранобэ; у идущих `chapters=0`, `volumes=0` |
| Shikimori | `GET /api/mangas/{id}/related` | 200; «Adaptation» с полем `anime` (id, russian, status: anons / ongoing / released) |
| Shikimori | серия быстрых запросов подряд | на 6–7-м ответ 429 (лимит 90 в минуту, 5 в секунду): бот ходит по одному запросу и редко |
| MangaDex | `GET /manga?title=…` | 200; находим запись, у которой `links.mal` равен нужному номеру; бывают «цветные версии» с тем же `mal` — берём ту, где больше языков |
| MangaDex | `GET /manga/{id}/aggregate?translatedLanguage[]=ru&translatedLanguage[]=en` | 200; `volumes` → `chapters`; «none» — главы без тома; ссылка с закодированными скобками (`%5B%5D`) принимается |
| MangaDex | `GET /manga/{id}/feed?limit=1&order[chapter]=desc…` | 200; `attributes.externalUrl` (официальная ссылка) или страница главы на MangaDex |
| MangaDex | поле `lastChapter` / `lastVolume` в записи | у идущих пусто, не используем |
| MangaUpdates | `POST /v1/series/search` (`type: ["Novel"]`), `GET /v1/series/{id}` | 200; `status` с числом томов; даты выхода томов нет |

Те же функции бота (`src/reading/sources.ts`), запущенные с ПК на открытых адресах: нашли «Кауру Хана» на MangaDex по номеру MAL, 199 глав и 24 тома, русский до 149, официальная ссылка; Shikimori и аниме по «Фрирен» (анонс «Золотая земля»); MangaUpdates: SAO 28 томов.

## Что бот честно может и не может

- **Может:** сказать «вышла глава N» / «вышел том N» по манге, если счётчик MangaDex вырос между двумя проверками (проверка раз в ночь); сказать «накопилось N» (вышло минус его «прочитал»); сказать «тайтл закончился» (Shikimori, раз в неделю); сказать, что идёт или анонсировано аниме по его манге или ранобэ.
- **Не может:** дату выхода главы (у MangaDex даты противоречивы: у одной и той же главы `publishAt` и `readableAt` расходились на два года, поэтому «когда вышла» не говорим; «вышла» — только по росту счётчика между проверками), новые главы названий, которых нет на MangaDex или у которых там нет ссылки на MAL, новые главы ранобэ (только тома, и только с MangaUpdates), выход на сайтах, которые читает Ihor.
- **Защита от мусора:** счётчик только растёт; скачок больше 100 за одну проверку не принимаем (чужая заливка); первая цифра по тайтлу — отправная точка, про неё не пишем.
