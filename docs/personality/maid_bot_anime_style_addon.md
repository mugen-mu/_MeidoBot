# Дополнение к ТЗ: аниме-стиль речи бота-горничной

Применять вместе с `maid_bot_personality_spec.md`. Первый файл описывает, КАКОЕ у горничной настроение и когда оно меняется. Этот файл описывает, КАК она при этом говорит и выглядит.

Главная идея: **аниме-стиль — отдельный слой поверх фразы**. Фраза хранится в нейтральной разметке с токенами, а отдельный рендерер превращает её в готовое сообщение в зависимости от настроения и настроек стиля. Так одну и ту же фразу можно показать на разных уровнях «анимешности» без переписывания.

---

## 1. Язык: кириллица или латиница

Решение по умолчанию:
- сам бот говорит по-русски
- японские слова пишутся **кириллицей**, как в русских фансабах и чатах: «ара-ара», «яре яре», «кудасай», «онэгай», «мендокусай»
- манга-звуки (SFX) по умолчанию пишутся **японской кана**, это даёт визуальный «мангa-вайб»: ゴゴゴゴ, ドキドキ
- латиница (`ara ara`, `yare yare`) доступна как опция в конфиге

Всё переключается настройкой, чтобы владелец мог сравнить варианты на практике.

## 2. Настройки стиля (config.yaml)

```yaml
anime_style:
  level: 2                 # 0 = обычный русский, 1 = лёгкие вставки, 2 = фансаб-стиль, 3 = полный отаку
  script: cyrillic         # cyrillic | latin | mixed (mixed = случайно по слову)
  sfx_script: kana         # kana | cyrillic | off
  honorifics: true         # -сама / -сан / -кун
  kaomoji: false           # включается автоматически на level 3
  max_interjections_per_message: 2
  word_cooldown_messages: 5   # одно и то же слово не чаще, чем раз в N сообщений
  translate_hints:
    enabled: true
    show_first_n_times: 2     # первые 2 использования слова даём перевод в скобках
  sfx_chance: 0.35            # шанс манга-звука на сообщение
```

Уровни:

| Level | Что включено |
|---|---|
| 0 | токены заменяются русскими эквивалентами: «ара» → «ой-ой», «яре яре» → «ну и ну» |
| 1 | 1 японское междометие на сообщение, без суффиксов и SFX |
| 2 | междометия + суффиксы (-сама), заикание, растяжки, редкие SFX |
| 3 | всё из level 2 + кавай-эмодзи/каомодзи, шёпот в спойлерах, чаще SFX, редкие «кинематографичные» моменты |

## 3. Словарь (файл personality/lexicon.yaml)

Структура записи: `id`, `cyrillic`, `latin`, `kana`, `meaning_ru`, `moods`, `situations`.

| id | Кириллица | Значение | В каких настроениях |
|---|---|---|---|
| `yare_yare` | яре яре | «ну и ну», усталый вздох | tired (главный маркер), tsundere |
| `ara_ara` | ара-ара | «ой-ой», мягкое удивление и поддразнивание | yandere, tired, proud |
| `mendokusai` | мендокусай | «как же лень / хлопотно» | tired |
| `shikata_nai` | сиката-най | «ничего не поделаешь» | tired, tsundere |
| `mou` | мо-о! | «ну вот опять!», раздражение | tsundere |
| `fun` | хмпф / фун | отворачивается, дуется | tsundere, sulking |
| `baka` | бака | «дурак» (по-доброму) | tsundere |
| `urusai` | урусай | «не шумите» | tsundere |
| `kudasai` | кудасай | «пожалуйста» | yandere (мольба), напоминания |
| `onegai` | онэгай | «прошу вас» | yandere, reminder_repeat |
| `gomen` | гомэн / гомэн-насай | «простите» | proud, sulking |
| `ganbatte` | ганбатте | «держитесь / вы справитесь» | proud, tired, reminder |
| `otsukare` | отсукарэ-сама | «спасибо за труд» | proud, done (иронично у tired) |
| `okaeri` | окаэри | «с возвращением» | return_after_pause |
| `daijoubu` | дайдзёбу | «всё в порядке?» / «я в порядке (нет)» | tired, proud |
| `ufufu` | уфуфу | смешок | yandere |
| `nee` | нэ-нэ | «послушайте...» | yandere, sulking |
| `hai` | хай | «да» | все |
| `eeh` | э-э?! | удивление | tsundere, proud |
| `haa` | ха-а... | вздох | tired, sleepy |

Обращения к пользователю по настроениям:
- `tired`: «госюдзин-сама» (с вздохом, формально)
- `tsundere`: без суффикса, «вы», иногда «бака-госюдзин»
- `yandere`: «госюдзин-сама~» с тильдой, иногда «аната» («вы», интимно)
- `proud`: «госюдзин-сама», но с редкой оговоркой «-кун... то есть сама!», смущается
- `sulking`: никак не называет, говорит в пустоту
- `sleepy`: путает, зевает посреди слова

Список слов должен легко расширяться: новое слово = новая запись в YAML, без правки кода.

## 4. Токены в фразах

В `phrases.yaml` фразы пишутся с токенами, рендерер их заменяет:

- `{yare_yare}`, `{ara_ara}`, `{kudasai}` и другие `id` из словаря: подставляется слово по `script` и `level`
- `{honorific}`: обращение по настроению
- `{sigh}`: вздох: `*вздох*` на level 0, `ハァ…` + «ха-а...» на level 2–3
- `{sfx:menace}`, `{sfx:heart}`, `{sfx:turn_away}`, `{sfx:stare}`, `{sfx:sleep}`: манга-звук по таблице ниже
- `{whisper:текст}`: тихое бормотание (см. раздел 5)
- `{stutter:х-хозяин}`: заикание по настроению

Если слово не подходит под текущее `level`, токен заменяется русским эквивалентом (`meaning_ru`) или пустотой, но предложение не должно ломаться.

## 5. Уровни реализации

### Уровень А — лексика
Вставка междометий и суффиксов из словаря, с учётом настроения (раздел 3). Лимиты: не больше `max_interjections_per_message` на сообщение, одно слово не чаще раз в `word_cooldown_messages`.

### Уровень Б — манера речи
Правила по настроениям:
- `tired`: паузы «...», вздохи, затянутые гласные («ну-у...»), обрывает фразу на полуслове
- `tsundere`: заикание на обращении («х-хозяин»), отрицание очевидного («я не переживаю!»), шёпотом договаривает правду
- `yandere`: тильды `~`, слишком вежливо, повторы, длинные паузы посреди фразы, улыбка «слишком долго»
- `sulking`: короткие фразы, ответы односложные, «...»
- `proud`: смущение, запинки, быстро берёт слова обратно
- `sleepy`: путает слова, зевает, обрывает

### Уровень В — манга-звуки (SFX)

| Звук | Кана | Когда |
|---|---|---|
| `menace` | ゴゴゴゴ | yandere, перед угрожающе-милой фразой |
| `heart` | ドキドキ | proud, смущение |
| `turn_away` | プイ | tsundere и sulking, отвернулась |
| `stare` | ジー | yandere и sulking, смотрит неотрывно |
| `sleep` | ぐぅ / zzz | sleepy |
| `sigh` | ハァ… | tired |
| `startle` | ハッ！ | неожиданность, возвращение хозяина |

Оформление SFX в Discord: отдельной строкой в **subtext**: `-# ゴゴゴゴ…`. Если `sfx_script: cyrillic`, пиши «гогого...», «доки-доки», «пуй».

Каомодзи (только level 3, не более одного на сообщение). **Обязательно экранируй спецсимволы Markdown** (`_`, `*`, `\`, `~`), иначе Discord сломает форматирование:
- tired: `(－_－;)`
- tsundere: `(｀へ´)`
- yandere: `(◕‿◕)`
- proud: `(//▽//)`
- sleepy: `(¦3[▓▓]`

### Уровень Г — оформление в Discord
- **Embed** с цветом по настроению (tired — серо-синий, tsundere — оранжевый, yandere — тёмно-красный, sulking — серый, proud — розовый, sleepy — фиолетовый)
- **Спрайты настроений:** по одной картинке на настроение (тема: оригинальная или сгенерированная горничная, **не вырезки из реальных аниме**). Показывать как thumbnail в embed, либо отправлять сообщения через вебхук с `avatar_url` по настроению. Аватар самого бота не менять (лимиты Discord)
- **Шёпот tsundere** в спойлере: `||...только не пропустите опять, онэгай||` (читать надо кликнуть, получается очень в тему)
- **Статус бота (activity)** по настроению: tired — «Играет: уборка (нехотя)», yandere — «Смотрит: на вас», sleepy — «Спит (нет)»
- **Реакция-эмодзи** на сообщение пользователя, соответствующая настроению
- **Задержка «печатает...»**: у `tired` и `sleepy` дольше, у `tsundere` быстро и резко, у `sulking` очень долго и потом одно слово

### Уровень Д — поведение и «обучение» пользователя
- **Подсказки перевода:** первые N использований слова сопровождаются переводом в скобках, например: «яре яре (ну и ну)...». После N раз перевод больше не показывается: пользователь «выучил» слово
- Команда `/glossary`: показывает слова, которые бот уже использовала, с переводом
- **Ответные реакции:** если пользователь сам пишет «ара-ара», «ганбатте», «окаэри» и т.п., бот это замечает и отвечает в тон (`affection +1`, не чаще раза в час)
- **Редкие моменты:** 1–2% шанс «кинематографичной» реплики (длинный монолог с SFX) на level 3

### Уровень Е — озвучка (необязательно, на потом)
Если решите добавить голос: TTS в голосовом канале, текст берётся из тех же фраз. Не использовать записи реальных сэйю или нарезки из аниме (авторские права). Закладывать в архитектуру только интерфейс `speak(text, mood)`, без реализации.

## 6. Пайплайн рендеринга

1. Выбрать фразу из пула по `mood` + `situation` (как в основном ТЗ)
2. Подставить переменные (`{user}`, `{task}`, `{miss_count}`)
3. Раскрыть токены лексики по `script` и `level`, соблюдая лимиты и кулдауны
4. Применить речевые эффекты настроения (раздел 5Б)
5. Добавить SFX с вероятностью `sfx_chance`
6. Добавить подсказку перевода, если слово ещё в первых N использованиях
7. Оформить: embed, subtext, спойлер, цвет, спрайт
8. Вернуть готовое сообщение + запись в лог (какие слова использованы)

Рендерер — чистая функция без обращений к Discord API, чтобы её можно было тестировать.

## 7. Пример: одна фраза на разных уровнях

Ситуация: напоминание «созвон в 15:00», настроение `tired`.

- **Level 0:** «Напоминание: созвон в 15:00. Опять я за вас всё помню.»
- **Level 1:** «Яре яре... Напоминание: созвон в 15:00. Опять я за вас всё помню.»
- **Level 2:** «Яре яре... Госюдзин-сама, напоминание: созвон в 15:00. Мендокусай, но... ганбатте.»
- **Level 3:** «*ハァ…* Яре яре (ну и ну)... Госюдзин-сама, напоминание: созвон в 15:00. Мендокусай... Но ладно. Отсукарэ-сама, заранее. (－_－;)»

Ситуация: третий пропуск, настроение `yandere`, level 3:
«Ара-ара~ Госюдзин-сама... третье напоминание. -# ゴゴゴゴ… Ответьте мне, кудасай~ Уфуфу... я подожду. Я всегда жду. (◕‿◕)»

Ситуация: второй пропуск, настроение `tsundere`, level 3:
«Мо-о! Бака! Это уже второй раз! Я ни капельки не переживаю! -# プイ ||только не пропустите опять, онэгай||»

## 8. Правила качества

1. **Суть напоминания всегда по-русски и понятна с первого взгляда.** Время, задача и важные детали никогда не прячутся в японизмы. Японские слова только «обёртка»
2. Не перегружать: лимиты на междометия и кулдауны обязательны. Если слов слишком много, это раздражает, а не смешит
3. Одно сообщение — максимум один SFX и одно каомодзи
4. При уходе из образа (серьёзные темы, плохое самочувствие хозяина) стиль отключается полностью до конца разговора
5. Все слова и SFX в одном месте (`lexicon.yaml`), чтобы можно было расширять без кода

## 9. Команды

- `/style level <0-3>`: уровень анимешности
- `/style script <cyrillic|latin|mixed>`: письменность
- `/style sfx <kana|cyrillic|off>`: манга-звуки
- `/hints <on|off>`: подсказки перевода
- `/glossary`: словарь использованных слов

## 10. Тесты и критерии готовности

1. Одна и та же фраза корректно рендерится на всех 4 уровнях и во всех 3 режимах `script`
2. На level 0 в тексте нет ни одного японского слова
3. Лимиты (междометия на сообщение, кулдауны слов) соблюдаются
4. Подсказки перевода показываются ровно первые N раз
5. Каомодзи не ломают Markdown
6. Время и название задачи в напоминании всегда читаемы по-русски
7. Все новые слова добавляются только через `lexicon.yaml`
