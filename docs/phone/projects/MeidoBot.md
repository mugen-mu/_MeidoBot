# MeidoBot

## 1. Что это и для кого
Личный Discord-бот Meido: напоминания, которые не исчезают, пока не нажато «Готово»; повторяющиеся дела; сводки; уведомления из публичных источников. Бесплатный Cloudflare Workers + D1, без включённого ПК.
Для кого: для владельца.

## 2. Архитектура
```
Discord → HTTP Interactions (подпись Ed25519) → Worker → D1
Cron раз в минуту → runCron (src/cron.ts) → D1 и Discord REST
Телефон-датчик → маршрут /power в Worker → сообщение о свете
Cron → внешние источники (свет, вода, газ, осадки, аниме)
Worker → Workers AI (опционально)
```
Worker без памяти: всё в D1, сбой подхватывает следующий запуск; время в базе UTC. Цикл cron: лестница настойчивости (0, +10, +20, +40 мин, затем «просрочено») → чтение текста приёма → сводки → источники. Слой личности — `src/personality/` (движок настроения, пул фраз «настроение → ситуация → фразы»); исходные ТЗ — `docs/personality/`, не править.

## 3. Структура репозитория
- `src/` — ядро (`time/` разбор фраз, `recur.ts`, `ladder.ts`, `service.ts`, `cron.ts`, `db/`, `discord/`), `personality/`, `anime/`, модули источников (`light.ts`, `water.ts`, `gas.ts`, `rain.ts`), `usage.ts` (учёт лимитов), `llm.ts`.
- `migrations/` — 9 миграций D1; `test/` — 52 файла vitest; `scripts/` — установка, `status`, `export`, сухой прогон; `design/` — страницы решений; `public/`, `assets/` — спрайты.

## 4. Принятые решения и почему
1. Дело не исчезает до «Готово»; исключение — автозаморозка через 30 дней без ответа (остаётся в базе, возвращается кнопкой). `CLAUDE.md`, `docs/DECISIONS.md`.
2. Бесплатный план с запасом; бот сам считает расход лимитов и предупреждает от 70%; платный — по признакам. `docs/CLOUDFLARE-PLANS.md`.
3. Приём текста — опрос внутри минутного cron, а не постоянное соединение (съело бы бесплатную норму). `docs/DECISIONS.md` (2026-11-10).
4. Всё в личные сообщения (кнопка «Личка»); панели «Горит» нет, про дела спрашивают текстом без модели. `docs/DECISIONS.md` (2026-11-11).
5. Правило кнопок: на виду пять команд и три кнопки под напоминанием, новое прячется в «Ещё». `CLAUDE.md`.
6. Модель — только запасной путь понимания фраз и реплики, по умолчанию выключена. `docs/DECISIONS.md` (2026-11-08), `docs/llm-probe-2026-11.md`.
7. Отдельный вход бота в Cloudflare (`.cf-home/`): общий вход на ПК — рабочий. `docs/DECISIONS.md`.
8. Источники: первое чтение молчит, сбой тихий (три неудачи подряд — поломка на экране «Состояние»); сторожа нет, «бот жив» — строка воскресной сводки. `docs/DECISIONS.md` (2026-11-10).

## 5. Нюансы и грабли
- Free: 10 мс процессора и 50 подзапросов на запуск (сухой прогон — до 11); cron стартует неточно.
- Discord: ответ за 3 секунды; даты в окне не выбрать; для чтения текста нужен Message Content Intent.
- Сайт бывает закрыт от ботов или недоступен из Cloudflare, хотя с ПК открывается: сначала проба из Worker (`docs/RECON-UTILITIES.md`).
- Случайность — только в словах личности, не во времени напоминаний.
- Замороженное дело — срабатывание с причиной закрытия; таблицу `occurrences` не пересоздавать.
- Текст, похожий на пароль или карту, бот не копирует: в базе только пометка.
- Выкладка — только по слову владельца, перед миграцией `npm run export`; wrangler — только через `npm run wrangler --`.

## 6. Как проверять
- `npm run check` (типы + 1128 тестов, зелёные), `npm run dry-run` (сутки на заглушках); на боевом `npm run status` (только чтение, нужен вход).
- Только человеку: настоящий Discord и Cloudflare — `LIVE-CHECKS.md` (107 шагов, открыто 90).
