# docs/inbox — заметки с телефона

Сюда облачная сессия Claude Code (вкладка Code в приложении Claude) сохраняет надиктованные мысли и фидбэк, пока ПК выключен. Правила — `CLAUDE.md`, «Облачная сессия». Разбирает их `/inbox` на ПК; обработанное лежит в `done/`.

Имя файла: `ГГГГ-ММ-ДД-meido-<тема>.md`.

```
# <тема коротко>
**Проект/репо:** Meido (_MeidoBot)

## Суть
<3 строки>

## Сырой текст
<дословно, как надиктовано>
```

«Сырой текст» не редактируется и не сокращается.
