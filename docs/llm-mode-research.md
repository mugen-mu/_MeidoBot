# Режим B (языковая модель) для Meido: бесплатные варианты

Дата исследования: 2026-11-07. Код не писался, ключи не запрашивались. Условия бесплатных тарифов меняются часто: перед внедрением цифры перепроверить (ссылки ниже).

## Вывод: что рекомендую и почему

1. **Cloudflare Workers AI.** Бот и так живёт на Cloudflare: отдельный аккаунт и карта не нужны, ключа нет (модель вызывается напрямую из бота), данные остаются у той же компании.
2. **Расход.** Бесплатно 10 000 «нейронов» в сутки. Для 50 коротких фраз в день по расчёту уходит примерно 300–1500 нейронов, то есть 3–15% суточной нормы (расчёт ниже, это оценка, не замер).
3. **Запасной вариант:** Google Gemini бесплатно. Лимиты у него щедрее, но на бесплатном тарифе Google может использовать ваши запросы для улучшения своих продуктов. Поэтому только для фраз без личного содержания (см. правило ниже).
4. **Всегда подстраховка:** если модель не ответила или лимит кончился, бот молча берёт готовую фразу из кода. Напоминание при этом не теряется и остаётся по-русски.
5. **Что не проверено:** качество русского у конкретных моделей Cloudflare. Сначала короткая проба на 10–20 фраз, потом решение (этап 0 плана).

## Детали и ссылки

### Cloudflare Workers AI (подтверждено по первоисточнику, страницы Cloudflare, даты на страницах)

[Pricing, обновлено 2026-10-20](https://developers.cloudflare.com/workers-ai/platform/pricing/)
- Лимит запросов: текстовые модели 300/мин; модели «только для платных» 20–50/мин. [Limits, обновлено 2026-09-17](https://developers.cloudflare.com/workers-ai/platform/limits/)
- Каталог: 73 модели, среди текстовых: gemma-4-26b-a4b-it, glm-4.7-flash, gpt-oss-20b/120b, llama-3.3-70b-instruct-fp8-fast, llama-3.1-8b-instruct-fp8, mistral-small-3.1, eurollm-9b-it (европейские языки), и др. Часть новых (часть DeepSeek, Kimi, GLM-5.x) требует платного способа оплаты. [Каталог, обновлён 2026-08-12](https://developers.cloudflare.com/workers-ai/models/)

- **Оценка расхода** (моя арифметика): 50 фраз в день, на каждую ~300 токенов входа (инструкция + настроение + текст дела) и 100 токенов выхода → 15 000 токенов входа и 5 000 выхода в сутки. gemma-4-26b: ~136 + ~136 ≈ 270 нейронов. llama-3.3-70b (самая дорогая из списка): ~400 + ~1020 ≈ 1400 нейронов. Обе в пределах 10 000.
- Вызов из Worker: в настройках `[ai] binding = "AI"`, в коде `await env.AI.run('<модель>', {...})`; без ключа. [Bindings, обновлено 2026-04-21](https://developers.cloudflare.com/workers-ai/configuration/bindings/)
- Не подтверждено: засчитывается ли вызов модели как «подзапрос» в лимит 50 на запуск cron; задержка (не измерял); русский у моделей. Ограничение процессорного времени 10 мс относится к работе кода, ожидание ответа модели обычно его не расходует, но на реальном боте проверить (в журнале уже были «Exceeded CPU»).

### Google Gemini API
- Бесплатный уровень есть, на странице цен в таблицах «Used to improve our products»: для бесплатного тарифа **Yes**, для платного **No**. [Pricing](https://aistudio.google.com/docs/pricing) (адрес ai.google.dev перенаправляет сюда)

[Rate limits](https://aistudio.google.com/docs/rate-limits) Исключение для ЕС/Великобритании/Швейцарии в проверенном тексте не нашёл; сторонний обзор утверждает, что оно есть, не подтверждено.
- Цифры «15 запросов/мин, 1000/сутки» встречаются только на форуме про прежнюю модель: не использовать.
- Вызов: обычный HTTPS-запрос с ключом (секрет Worker), без привязки.

### Ollama на ПК
Только для опытов дома: ПК у вас не всегда включён, а боту нужно ходить на него через туннель. В бота как рабочий путь не закладываем.

### Правило: что можно отдавать модели
Отдавать: настроение (слово), тип ситуации («пропущено», «выполнено», «напоминание»), время и **название дела только когда оно не личное**.
Не отдавать никогда: пароли и подсказки к ним, пометку «от чего это», адреса, телефоны, суммы, здоровье и горе (стиль на этих темах и так выключен по ТЗ), имена других людей.
Практичный вариант: модель сочиняет **только вступительную или заключительную реплику** по настроению, а текст дела бот вставляет сам, мимо модели. Тогда личные данные не уходят вообще, и суть напоминания всегда читаема. Для Cloudflare это необязательно строго, для Gemini бесплатного — обязательно.

### Красивая деградация
1. Таймаут около 2 секунд (ответ на команду Discord должен уйти за 3 с; иначе «отложенный» ответ).
2. Любая ошибка, лимит, пустой или слишком длинный/не-русский ответ → готовая фраза из кода (`flavor.ts`/`src/personality/`).
3. Счётчик «модель за сутки отказала N раз» → после нескольких отказов подряд бот сутки не обращается к модели.
4. Фраза от модели проходит проверку: длина, нет ссылок, нет запрещённых слов, в основном кириллица.
5. Пользователь видит режим в `/mood` или `/style` («живой / по заготовкам»), без сообщений об ошибках.

## Что ещё надо решить пользователю
1. Начать с Cloudflare Workers AI и только на пробу русского (рекомендую): да? Это бесплатно и без новых аккаунтов.

## Черновой план внедрения
0. Проба качества: 10–20 типовых ситуаций, 3–4 модели Cloudflare (gemma-4, glm-4.7-flash, llama-3.3-70b, eurollm), оценка русского и стиля «усталая горничная»; выбор модели. Заодно замер задержки и расхода нейронов.
1. Привязка `AI` в настройках Worker, обёртка вызова с таймаутом и проверкой ответа (отдельный модуль, без влияния на остальное).
2. Системный промпт из ТЗ (раздел режима B) + фильтр данных по правилу выше.
3. Подключение в 2–3 точки (после «Готово», после пропуска, сводка), везде с запасной готовой фразой.
4. Счётчик отказов, суточный выключатель, режим в `/style`.
5. Тесты: ответ модели ошибочный, пустой, на английском, слишком длинный, таймаут; проверка, что личное не уходит.
6. Живая проверка на настоящем боте: задержка, «Exceeded CPU», расход нейронов за неделю.
7. Запись в журнал, правило пересмотра: раз в месяц проверить условия бесплатной квоты.
