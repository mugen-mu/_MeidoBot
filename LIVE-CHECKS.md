# DiscordBot: живые проверки

После установки по `README.md`. Каждый шаг около 2 минут. Не блокирует работу: отметьте, что получилось, остальное оставьте. Что не так — одной строкой («шаг 6: окно пустое»), разберу.

- [x] **1. Сводка.** (`npm run status` выполнен агентом 2026-11-07: «Cron: работает», хозяин назначен, каналы заведены, проблем нет) В папке бота: `npm run status`. Ждём: «Cron: работает», «Хозяин бота: назначен», «Каналы: заведены».
- [x] **2. Текст в канале «бот».** (ок, 2026-11-07, со слов пользователя) Напишите там `через 2 минуты проверка`. Ждём ответ «Записано …» в течение минуты. Нет ответа — в `/settings` нажмите «Личка: включить» и напишите то же боту в личные сообщения (бот сам подсказывает, если не видит текст канала).
- [x] **3. Напоминание и кнопки.** (ок, 2026-11-07, со слов пользователя) Через 2 минуты в канале «напоминания» придёт сообщение с упоминанием. Нажмите «15 мин» (станет «Отложено»), потом «Готово».

README «Где споткнуться»), после этого «вроде работает» со слов пользователя) В личном чате с любым человеком или с самим собой: `/remind завтра в 10 тест`. Ждём ответ, видимый только вам (так работает установка «на аккаунт»).
- [x] **5. Меню сообщения.** (ок, 2026-11-07, со слов пользователя: «вроде работает») Долгое нажатие на любое сообщение → Приложения → «Напомнить об этом». Ждём вопрос «когда напомнить?» или «Записано».
- [x] **6. Окно «На…».** (ок, 2026-11-07, со слов пользователя: «вроде работает»; какой вариант выбора был — радио или строка — не уточнено) На сообщении-напоминании кнопка «На…»: должно открыться окно с вариантами (круглые кнопки) и строкой «Своё время». Выберите вариант или впишите «завтра 10:30». Если вариантов нет или Discord пишет ошибку, напишите об этом: строка всё равно работает.
- [x] **7. Третье откладывание.** (ок, 2026-11-07, со слов пользователя: «вроде работает») Нажмите «15 мин» три раза на одном напоминании. На третий раз бот спросит «сегодня / разбить на шаги / удалить».
- [ ] **8. Настройки.** `/settings`: включите «Тихие часы», откройте «Время тишины…» и «Сводки и пояс…», выключите обратно.
- [ ] **9. Таймер.** `/every 20 минут проверить плиту до 23:59`: сообщения идут каждые 20 минут, старое удаляется; кнопка «Стоп» останавливает.
- [ ] **10. Панель «Горит».** Оставьте одно напоминание без «Готово»: в канале «сегодня» в течение 5 минут появится панель «Горит», дальше она правится на месте.
- [ ] **11. Телефон.** Придёт ли push на iPhone при упоминании в канале «напоминания» (проверьте звук и режим «Не беспокоить»).
- [ ] **12. Сторож.** На healthchecks.io статус проверки `Meido` — «Up» через 10–15 минут после установки.
- [ ] **13. Свет.** `/settings` → «Свет: группа…» → впишите `3`. В ближайшей утренней (08:00) или вечерней (20:00) сводке должна появиться строка «Свет сегодня (группа 3): света не будет …» — сверьте с сайтом ДТЕК («Лінія 1»). Вечером после публикации — «Свет завтра …».
- [x] **14. Характер.** (ок, 2026-11-07, со слов пользователя) `/settings` → кнопка «Характер: уставшая горничная». Затем `/list` при пустом списке (в ответе появится приписка), «Готово» на любом напоминании (под «Готово: …» мелкая строка), утренняя сводка (подпись «Бот на месте… …»). Кнопка «Характер: нейтральный» возвращает прежний тон. Напоминания сами не меняются.
- [ ] **15. Ответ на напоминание.** На сообщении-напоминании нажмите Reply (ответить) и напишите `через 2 мин` (или `на час`, `завтра 10:30`): в течение минуты сообщение станет «Отложено…», бот коротко ответит «Отложено: … Напомню: …». Ответ `готово` закрывает дело. Ответ на старую копию (уже удалённую лестницей, Discord пишет «Original message was deleted») тоже должен работать. Обычный текст в канале «напоминания» без Reply игнорируется.
- [ ] **16. Время сообщения.** В канале «бот» напишите `через 2 минуты проверка`. Напоминание должно прийти через 2 минуты после **отправки вашего сообщения** (плюс до минуты на сам бот), а не после его ответа «Записано».
- [ ] **17. Свет: ссылки.** Введите `/power`: ответ виден только вам, в нём две ссылки (`…/off` и `…/on`), без картинки-предпросмотра. Откройте ссылку `…/off` в браузере компьютера: должно появиться слово `started`; через минуту в «напоминаниях» придёт «Света нет с …» с упоминанием. Откройте `…/on`: «Свет вернулся в …, не было … мин». Ключ с ссылки уберите из ссылки и откройте снова: `unauthorized`.
- [ ] **18. Свет: телефон.** По `docs/POWER-SENSOR.md` (MacroDroid на Samsung SM-J730FM/DS, ~15 минут): выдернуть зарядку на минуту и вставить; потом на 10–20 секунд (ничего не должно прийти). Исключение приложения из «спящих» сделано.
