## Главное, что нельзя потерять
- **Напоминание не исчезает, пока пользователь не нажал «Готово».** «Отложить» не закрывает дело. Повторяющееся дело: каждое повторение — отдельная запись, пропущенное не стирается.
- Бесплатно; Cloudflare Workers + D1; Discord по HTTP Interactions; всё работает без включённого ПК.
- Календарь Google и другие чужие сервисы не подключаем (решение пользователя 2026-11-07): всё внутри Discord.
- Ничего из «идей» не внедрять без его «да»: сначала предложить простыми словами, дождаться ответа.

## Правила проекта
- **Личные аккаунты.** Cloudflare и Discord — только личные пользователя. Корпоративные токены, аккаунты, организации не использовать.
- **Секреты** (токен бота, ключ Discord, ключ для Siri) — только `wrangler secret`, `.dev.vars` (в `.gitignore`) и менеджер паролей. Не в git, не в чате, не в журнале. Скрипт установки спрашивает значения у пользователя в консоли.
- **Установка и деплой — одним действием** (`setup.cmd` / `npm run setup`), без ручной правки кода и конфигов. Вход в Cloudflare (`wrangler login`) и создание приложения в Discord Developer Portal делает пользователь по README; выкладку готового и проверенного — агент, с понятным отчётом.
- **Интерфейс бота и документы — по-русски**, простыми словами, без жаргона (пользователь не программист). Идентификаторы — по-английски.
- **Безопасность текста.** Сообщения, похожие на пароль, ключ или номер карты, бот не копирует, не индексирует, не пишет в журнал: в базе только пометка «от чего это» (без значения и его частей). Сообщение сам не удаляет молча: спрашивает «от чего это?», напоминает перенести в Bitwarden и удаляет по кнопке.
- **Настройки, а не константы.** Тихие часы, режим «я в отъезде», время сводок и настойчивость переключает сам пользователь в `/settings`; значения по умолчанию в коде — только стартовые.
- **Правда в отчётах.** Деплой отсюда не проверить без входа пользователя в Cloudflare: в отчёте всегда «Проверено локально / Не проверено на настоящем Discord и Cloudflare».
- **Коммиты** — префикс `DiscordBot:`, только своими путями (правила корня). Данные пользователя (дела, заметки, дамп базы) в git не кладём.
