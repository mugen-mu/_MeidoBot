# DiscordBot: что открыто

Новое сверху. Решённое переезжает в `docs/DECISIONS.md`.

1. **Первый запуск на живом боте — ждёт пользователя (~15 минут).** Код этапа 2 готов: `setup.cmd`, `README.md` по кликам, `npm run status`, `npm run export`, `LIVE-CHECKS.md` (12 шагов по 2 минуты). Что делает пользователь: приложение в Discord Developer Portal (README, шаг 1), двойной щелчок `setup.cmd` (вход в Cloudflare, три значения), три действия в Discord (адрес Interactions Endpoint URL, ссылки установки, `/setup`), по желанию сторож на healthchecks.io. Если что-то упадёт на живом — писать шаг и текст ошибки, чинит сессия по DiscordBot.
2. **Что подтвердит живой запуск** (в коде заложено с запасом): читается ли текст канала «бот» без постоянного соединения (если нет — «Личка» в `/settings`); значение «радио» в окне «На…» (читается `value` и `values`, запасной путь — строка «завтра 10:30»); окно из кнопки; команда-меню без описания; право «Управлять каналами» для `/setup`; push при упоминании; хватает ли 10 мс процессорного времени на запуск (панель Cloudflare → Workers → Logs, ищем «Exceeded CPU»); `wrangler d1 create --location eeur`, `d1 migrations apply` без вопроса, `deploy` в неинтерактивном режиме — установка писалась по справке wrangler, на настоящем аккаунте не запускалась.
3. **Сводка по графику света** (DESIGN §15). Город пользователя — Днепр (ДТЕК Дніпровські електромережі). Открытые данные Yasno для Днепра работают: `https://app.yasno.ua/api/blackout-service/public/shutdowns/regions/3/dsos/301/planned-outages` (проверено с ПК 2026-11-07: 12 групп 1.1–6.2, у каждой `today`/`tomorrow`; «завтра» до публикации — `WaitingForSchedule`). Сверка со скриншотом сайта ДТЕК показала: у дома пользователя «складная схема» (Лінія 1 / Лінія 2); **Лінія 1 = группа 3** (на 07.11 график 06:30–14:00 и 17:00–21:00 совпал точно; 3.1 и 3.2 сегодня одинаковы). **Ждём от пользователя:** скриншот вкладки «Лінія 2» (и, когда в ~20:00 появится «на завтра», скриншоты «на завтра» для обеих линий — по ним различим 3.1/3.2). Адрес дома в репозиторий не пишем: бот хранит только группы. Дальше: модуль `src/light.ts` (запрос Yasno раз в сводку, кэш, две линии подписью «Лінія 1/2»), настройка групп в `/settings`, строка в утренней и вечерней сводке; проверить GET Yasno из Worker.
4. **Не сделано в ядре (заготовки в базе есть):** погода в утренней сводке, «Прочитать позже», шаблоны рутин, команда `/export` в самом Discord (сейчас копия — `npm run export`), правка самого повтора у повторяющегося дела, пометка «от чего это?» для секретов и кнопка «удалить сообщение» (сейчас бот отказывается сохранять пароль/ключ/карту и советует Bitwarden; в базу и журнал значение не попадает).
5. **Отложено пользователем.** Siri и «Поделиться» на iPhone («ничего не понял»: если вернёмся, объяснить проще, по шагам и с картинками). «Голосовое в текст» и «текст в канал Входящие» не выбраны. «Привычки с серией дней» не берём сейчас (возможность оставить, F1).
6. **Этап 4** («Входящие»-форум с тегами, Meido: поиск, дубли, недельная уборка по «Входящим», пометка «от чего это» для паролей, архив). Недельные итоги уже есть в ядре.
