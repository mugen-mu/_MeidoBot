# DiscordBot: что открыто

Новое сверху. Решённое переезжает в `docs/DECISIONS.md`.

1. **Этап 1 — ядро** (время, повторы, лестница, база, слой Discord, cron, настройки) — в свежей сессии по `/handoff`; бриф опирается на `docs/DESIGN.md` (раздел 0 главнее) и `docs/DECISIONS.md`.
2. **Этап 2 — установка** (`setup.cmd`, README, `/setup` заводит каналы). Здесь нужен пользователь, ~10 минут: создать приложение в Discord Developer Portal (установка на сервер и на пользователя; включить Message Content Intent), войти в Cloudflare (`wrangler login`), создать сторожа на healthchecks.io.
3. **Живые проверки на этапе 2.** Читается ли текст канала «бот» через REST без постоянного соединения (если нет, приём в личке); обновление ссылок на старые вложения; приходит ли push при упоминании в канале; работает ли «Меню на сообщении» из чужого чата при установке бота «на пользователя».
4. **Сводка по графику света** (DESIGN §15): вопрос к пользователю — город или область и номер группы (или адрес); проверить GET Yasno из Worker; для ДТЕК запасной путь с домашнего ПК.
5. **Отложено пользователем.** Siri и «Поделиться» на iPhone («ничего не понял»: если вернёмся, объяснить проще, по шагам и с картинками). «Голосовое в текст» и «текст в канал Входящие» не выбраны. «Привычки с серией дней» не берём сейчас (возможность оставить, F1).
6. **Этап 3** (способы записи: приём текста, меню сообщения, `/remind`, `/every` — часть уже в ядре) и **этап 4** («Входящие»-форум, Meido: поиск, дубли, уборка, шаблоны рутин, пометка «от чего это» для паролей).
