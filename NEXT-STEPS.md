# DiscordBot: что открыто

Новое сверху. Решённое переезжает в `docs/DECISIONS.md`.

1. **Этап 2 — установка** (следующий). Нужен пользователь, ~10 минут. Что сделает агент: `setup.cmd` / `npm run setup` (создать базу D1 `wrangler d1 create meido`, вписать `database_id` в `wrangler.toml`, `wrangler d1 migrations apply meido --remote`, спросить в консоли ключи и положить `wrangler secret put`, `wrangler deploy`, `npm run register`), README по кликам. Что сделает пользователь по README:
   - создать приложение в Discord Developer Portal: Installation → оба способа установки (сервер и пользователь), права бота — View Channels, Send Messages, Read Message History, Manage Channels (для `/setup`), Manage Messages (удалять по кнопке, этап 4); включить **Message Content Intent**; в General Information взять Application ID и Public Key, в Bot — токен;
   - войти в Cloudflare (`wrangler login`), указать адрес `https://<имя>.workers.dev/interactions` в поле Interactions Endpoint URL;
   - завести проверку на healthchecks.io (период 10 минут, запас 30), адрес — в секрет `WATCHDOG_URL`;
   - в Discord выполнить `/setup` на своём сервере (хозяин бота — тот, кто выполнил первым).
2. **Живые проверки на этапе 2** (в код заложено с запасом, подтвердить на живом боте): читается ли текст канала «бот» без постоянного соединения (если нет — включить «личку» в `/settings`; бот сам напишет подсказку); приходит ли `value` у «радио» в окне «На…» (в коде читается и `value`, и `values`; запасной путь — строка «завтра 10:30»); открывается ли окно из кнопки; регистрируется ли команда-меню без описания; приходит ли push при упоминании в канале; хватает ли 10 мс процессорного времени на запуск (если нет — подсказка в журнале Cloudflare «Exceeded CPU»); работает ли «Напомнить об этом» из чужого чата при установке «на пользователя»; обновление ссылок на старые вложения.
3. **Сводка по графику света** (DESIGN §15): вопрос к пользователю — город или область и номер группы (или адрес); проверить GET Yasno из Worker; для ДТЕК запасной путь с домашнего ПК.
4. **Не сделано в ядре (заготовки в базе есть):** погода в утренней сводке, «Прочитать позже», шаблоны рутин, `/export` (копия в файл), правка самого повтора у повторяющегося дела, пометка «от чего это?» для секретов и кнопка «удалить сообщение» (сейчас бот отказывается сохранять пароль/ключ/карту и советует Bitwarden; в базу и журнал значение не попадает).
5. **Отложено пользователем.** Siri и «Поделиться» на iPhone («ничего не понял»: если вернёмся, объяснить проще, по шагам и с картинками). «Голосовое в текст» и «текст в канал Входящие» не выбраны. «Привычки с серией дней» не берём сейчас (возможность оставить, F1).
6. **Этап 4** («Входящие»-форум с тегами, Meido: поиск, дубли, недельная уборка по «Входящим», пометка «от чего это» для паролей, архив). Недельные итоги уже есть в ядре.
